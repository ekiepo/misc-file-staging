05 · Use Cases

How this gets used.

Use different QR IDs to learn which placement, handout, or follow-up is working.

For Marketing

  • Put separate QR codes on packaging, trade ads, dealer sheets, and event signage.
  • Send two codes to the same page when the destination is the same but the placement needs separate reporting.
  • Compare campaign groups to see which material is driving scans.
  • Change the final destination after print when a page, video, or spec sheet changes.
  • Use top performers and recent activity to decide which placements deserve more support.

For Sales

  • Use a QR code in a meeting to open the current manual, spec sheet, or demo video on a phone.
  • Give each leave-behind or dealer packet its own code, even when it points to the same document.
  • Track which follow-up links get scanned after a sales call or sample handoff.
  • Route a printed code to the best current asset without reprinting old materials.
  • Use scan activity to see which topics are getting attention before the next conversation.

06 · Access

Access, handoff, and next steps.

Where the hub, final files, QR platform, and update process should live.

Hosting

Currently hosted on Vercel. The manual pages, spec sheets, and document downloads can be ported to the Dauer site as the final destinations.

QR platform and data

The QR tracking platform should stay on Vercel. Scan data can be exported, and the registry is backed by Supabase so destinations, counts, and state persist.

Next steps

Confirm with the Dauer web team how manuals, PDFs, and downloads will be updated once hosted on the Dauer site, so ongoing changes are easy to make.
